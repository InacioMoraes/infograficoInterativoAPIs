05 · Missão concluída

Você percorreu o fluxo básico de uma comunicação HTTP.

GET → consultar
POST → criar/enviar
PUT / PATCH → atualizar
DELETE → excluir
2xx → sucesso · 4xx → erro relacionado à requisição/acesso
Evidência de aprendizagem: explique por que PATCH é adequado para alterar apenas parte de um recurso e dê um exemplo de código de sucesso.
